# Odpovědi pojišťoven

Sem patří plné znění odpovědí zdravotních pojišťoven na kola dotazů.

- Jeden soubor na pojišťovnu a kolo, pojmenovaný `YYYY-MM-DD_<kod>_<zkratka>_kolo<N>.md`.
- Odpovědi se zveřejňují doslova, bez úprav a zkracování (viz `docs/metodika-srovnavac-pojistoven.md`, § 4.2).
- Adresář zatím neobsahuje žádné odpovědi; soubory přibývají s každým kolem dotazů.
